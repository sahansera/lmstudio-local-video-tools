# Code of Conduct

We want Local Video Tools for LM Studio to be a constructive, welcoming open-source project for contributors of all experience levels.

## Expected behavior

Participants should:

- be respectful and professional;
- critique ideas and code rather than people;
- assume good intent while remaining clear about technical concerns;
- welcome questions from newcomers;
- give actionable feedback;
- respect privacy, especially when discussions involve local files or media;
- avoid harassment, discrimination, intimidation, or deliberately disruptive behavior.

## Unacceptable behavior

Examples include personal attacks, discriminatory or sexualized comments, threats, doxxing, repeated unwanted contact, deliberate disruption, or publishing another person's private information without permission.

## Scope

This applies to repository issues, pull requests, discussions, reviews, and other project spaces associated with Local Video Tools for LM Studio.

## Reporting

If you experience or observe unacceptable behavior, contact the repository owner privately. Reports will be reviewed in context and handled as fairly and discreetly as possible.

Maintainers may edit or remove comments, close discussions, restrict participation, or take other reasonable action when behavior undermines the project community.
